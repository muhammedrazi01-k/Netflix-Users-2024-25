# 🎬 Netflix Users Analytics Dashboard

## 📌 Project Overview

The **Netflix Users Analytics Dashboard** is an interactive data visualization project developed to analyze Netflix user subscriptions, demographics, country-wise distribution, genre preferences, and viewing behavior.

The dashboard provides valuable insights into user engagement, subscription trends, popular content genres, and average watch hours through interactive filters and visualizations.

This project helps understand customer preferences and subscription patterns, enabling better data-driven decisions for improving user experience and subscription strategies.

## 🎯 Project Objectives

- Analyze the total number of Netflix users.
- Understand subscription distribution across different countries.
- Analyze user demographics based on age groups.
- Compare Basic, Premium, and Standard subscriptions.
- Identify popular content genres among subscribers.
- Analyze yearly subscription trends.
- Compare average watch hours across subscription types.
- Understand user preferences based on subscription categories.

## 📊 Dashboard Highlights

### 1. Total Users

- Displays the overall number of Netflix users.
- Total users: **25,000**.
- Provides an overview of the user base represented in the dataset.

### 2. Subscription Type Filter

Allows users to interactively filter the dashboard based on three subscription plans:

- Basic
- Premium
- Standard

This helps compare user behavior and engagement across different subscription plans.

### 3. Country Filter

Users can filter the dashboard based on geographical locations, including:

- Germany
- India
- Japan
- Other available countries.

This feature helps analyze country-specific subscription patterns.

### 4. Age Filter

The dashboard provides age-based filtering to explore user demographics.

It helps understand how different age groups interact with Netflix subscription plans.

### 5. Age vs Country Analysis

This chart visualizes the distribution of Netflix users across different age groups and subscription types.

Key observations:
- Compares user distribution across multiple age groups.
- Shows the number of Basic, Premium, and Standard subscribers.
- Helps identify subscription preferences among different age groups.

### 6. Subscription vs Country

A pie chart represents the geographical distribution of Netflix subscriptions.

Countries represented include:

- Australia
- Brazil
- Canada
- France
- Germany
- India
- Japan
- Mexico
- UK
- USA

**Key Insight:** The country-wise subscription distribution is relatively balanced, with most countries contributing approximately 10% each.

### 7. Year vs Subscription Analysis

A line chart compares subscription counts across different years and subscription types.

Subscription categories:
- Basic
- Premium
- Standard

Years analyzed:
- 2024
- 2025

**Key Insight:** The visualization helps identify changes in subscription counts between the two years and compare the performance of different subscription plans.

### 8. Genre vs Subscription Type

This chart analyzes the relationship between content genres and subscription types.

Genres include:
- Action
- Comedy
- Documentary
- Drama
- Romance
- Sci-Fi

**Key Insight:** The visualization helps understand genre preferences across Basic, Premium, and Standard subscribers.

### 9. Premium Subscription vs Genre

A horizontal bar chart displays the number of users associated with different content genres under the Premium subscription category.

Genre-wise user counts:

| Genre | Number of Users |
|---|---:|
| Sci-Fi | 3,465 |
| Romance | 3,572 |
| Horror | 3,654 |
| Drama | 3,533 |
| Documentary | 3,636 |
| Comedy | 3,561 |
| Action | 3,588 |

**Key Insight:** Horror has the highest displayed user count, followed by Documentary, while Sci-Fi has the lowest.

### 10. Average Watch Hours vs Subscription

A 3D column chart compares average watch hours across subscription plans.

Subscription types:
- Basic
- Premium
- Standard

**Key Insight:** Basic subscribers have the highest displayed average watch hours, followed by Premium and Standard subscribers.

This analysis helps evaluate viewing engagement across subscription categories.

## 🔍 Key Business Insights

1. **User Base:** The dashboard represents a total of 25,000 Netflix users.

2. **Geographical Distribution:** Subscription distribution across the displayed countries is relatively balanced.

3. **Subscription Analysis:** The dashboard compares three major subscription plans: Basic, Premium, and Standard.

4. **Genre Preferences:** Horror has the highest displayed user count in the Premium genre analysis, with 3,654 users.

5. **Documentary Engagement:** Documentary content also demonstrates strong user engagement, with 3,636 users.

6. **Age Demographics:** The age-based analysis helps identify subscription preferences among different age groups.

7. **Yearly Trends:** The yearly subscription chart provides a comparison of subscription counts between 2024 and 2025.

8. **Viewing Behavior:** Basic subscribers have the highest displayed average watch hours among the three subscription plans.

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Dashboard development and data visualization.
- **Pivot Tables** – Data summarization and analysis.
- **Pivot Charts** – Interactive graphical representations.
- **Slicers** – Dynamic filtering and dashboard interaction.
- **Data Analysis** – User segmentation and subscription analysis.

## 💡 Conclusion

The Netflix Users Analytics Dashboard provides an interactive overview of subscription patterns, user demographics, geographical distribution, genre preferences, and viewing behavior.

The analysis highlights differences in user engagement across subscription plans and content genres. Horror and Documentary show strong user counts in the Premium genre analysis, while Basic subscribers have the highest displayed average watch hours.

Overall, this dashboard demonstrates how data analytics and visualization can transform raw user information into meaningful business insights, helping streaming platforms understand customer behavior and improve subscription strategies.
